# Flight Booking Web UI

A modern and clean front-end user interface prototype designed for a flight reservation platform. 

## 🚀 Tech Stack
* **HTML5** - Semantic layout and structure
* **CSS3** - Custom styling, layout design, and component UI

## ✨ Key Features
* User-friendly flight search card component
* Promotional campaign cards section
* Clean navigation bar structure
* Responsive design layout for desktop and mobile screens

## 🛠️ How to Run
1. Download or clone this repository.
2. Open `index.html` directly in any web browser.
